# SpicyBooks 添加书籍完整流程与字段说明

## 概述

SpicyBooks 使用 Cloudflare D1 (SQLite) 数据库存储书籍数据。通过后台管理系统 `/admin` 添加新书，数据直接写入数据库，无需重新构建网站。前台页面通过 `revalidate = 3600`（1小时缓存）自动刷新数据。

---

## 一、添加书籍的完整流程

### 1. 登录后台
- 访问 `/admin`，输入管理员密码登录
- 密码存储在 Cloudflare 环境变量 `ADMIN_PASSWORD` 中
- 登录成功后自动跳转到 `/admin/books`

### 2. 进入添加页面
- 在书籍列表页点击「添加新书」按钮
- 跳转到 `/admin/books/new`，进入五步表单

### 3. 五步表单填写

#### 步骤一：基础信息
1. 输入 ISBN，点击「获取信息」→ 自动从 Google Books API 填充基础字段
2. 自动填充的字段可手动修改
3. 输入 ASIN → 自动生成 Amazon Associates 链接
4. 书名输入后自动生成 slug（可手动覆盖）

#### 步骤二：Spice 信息
- 设置辣度等级、辣度描述、场景数量、蒸汽等级、POV 风格

#### 步骤三：标签和分类
- 勾选已有的 Tropes（多选）
- 添加子类型、内容警告、阅读氛围标签

#### 步骤四：编辑内容
- 撰写编辑评论
- 添加「适合阅读」和「不适合阅读」条目

#### 步骤五：关联数据
- 选择相似书籍
- 填写系列信息（系列名、第几本、总共几本）
- 填写有声书朗读者

### 4. 提交保存
- 点击提交，API 将数据写入 `books` 表和 `book_tropes` 关联表
- 使用 `db.batch()` 保证原子性操作

## 三、表单字段与数据库字段的对应关系

### 步骤一：基础信息

| 表单字段 | 数据库字段 | 说明 |
|----------|-----------|------|
| ISBN | `isbn` | 可通过 Google Books API 自动填充其他字段 |
| 书名 | `title` | 必填，ISBN 可自动填充 |
| Slug | `slug` | 从书名自动生成，可手动修改 |
| 作者 | `author` | 必填，ISBN 可自动填充 |
| 描述 | `description` | ISBN 可自动填充 |
| 页数 | `page_count` | ISBN 可自动填充 |
| 出版年份 | `publish_year` | ISBN 可自动填充 |
| 封面 URL | `cover_url` | ISBN 可自动填充 |
| ASIN | → `amazon_url` | 输入 ASIN，自动拼接为完整 Amazon URL |

### 步骤二：Spice 信息

| 表单字段 | 数据库字段 | 说明 |
|----------|-----------|------|
| 辣度等级 | `spice_level` | 0-5 滑块，必填 |
| 辣度描述 | `spice_description` | 详细描述辣度内容 |
| 辣味场景数 | `spicy_scene_count` | 大约有多少个辣味场景 |
| 蒸汽等级 | `steam_level` | 如 "Steamy", "Scorching" 等 |
| POV 风格 | `pov_style` | 如 "Dual POV", "First Person" 等 |

### 步骤三：标签和分类

| 表单字段 | 数据库字段 | 说明 |
|----------|-----------|------|
| Tropes | `book_tropes` 关联表 | 多选已有 tropes |
| 子类型 | `subgenres` | JSON 数组，如 ["Contemporary Romance", "Romantic Comedy"] |
| 内容警告 | `content_warnings` | JSON 数组，如 ["Explicit sexual content", "Strong language"] |
| 阅读氛围 | `moods` | JSON 数组，如 ["Funny", "Steamy", "Feel-good"] |

### 步骤四：编辑内容

| 表单字段 | 数据库字段 | 说明 |
|----------|-----------|------|
| 编辑评论 | `editorial_review` | 网站编辑的推荐语 |
| 适合阅读 | `perfect_for` | JSON 数组，如 ["Fans of enemies-to-lovers", "Readers who love witty banter"] |
| 不适合阅读 | `skip_if` | JSON 数组，如 ["You prefer slow-burn romance", "You don't like explicit content"] |

### 步骤五：关联数据

| 表单字段 | 数据库字段 | 说明 |
|----------|-----------|------|
| 相似书籍 | `similar_books` | JSON 数组，存储其他书籍的 slug |
| 系列名称 | `series_name` | 如 "Twisted" |
| 系列编号 | `series_number` | 第几本 |
| 系列总数 | `series_total_books` | 系列共几本 |
| 朗读者 | `narrator` | 有声书朗读者姓名 |

## 四、书籍详情页展示的所有内容

前台 `/books/[slug]` 页面展示以下区块：

1. **Hero 区域**：封面图、书名、作者、页数、出版年份、POV 风格、朗读者、子类型标签、Amazon 购买按钮
2. **Quick Spice Verdict**：辣度评分、蒸汽等级、辣味场景数、POV 风格
3. **About**：书籍描述、阅读氛围标签 (moods)
4. **Spice Breakdown**：辣度等级、辣度描述、辣度进度条
5. **Tropes**：所有关联的 tropes（emoji + 名称 + 描述）
6. **Content Warnings**：内容警告列表
7. **Who Should Read This**：适合阅读 (perfect_for) / 不适合阅读 (skip_if)
8. **Our Take**：编辑评论 (editorial_review)
9. **Reader Reviews**：读者评论列表（用户名、辣度评分、评论内容）
10. **Series Info**：系列信息（如果有的话）+ 同系列其他书籍
11. **FAQ**：自动生成的常见问题（辣度、tropes、内容警告、系列等）
12. **Similar Books**：相似书籍推荐卡片
13. **Bottom CTA**：底部 Amazon 购买按钮

## 五、Spice Level 等级说明

| 等级 | 标签 | 描述 |
|------|------|------|
| 0 | No Spice (Clean) | 无浪漫或亲密内容 |
| 1 | Mild (Fade to Black) | 有浪漫但亲密场景淡出 |
| 2 | Warm (Closed Door+) | 有暗示性内容但不明确描述 |
| 3 | Spicy (Moderate Scenes) | 明确的亲密场景，适度描述 |
| 4 | Very Spicy (Explicit) | 详细的明确亲密场景 |
| 5 | Scorching (Very Explicit) | 非常详细且频繁的亲密场景 |

## 六、API 路由一览

| 路径 | 方法 | 说明 |
|------|------|------|
| `/api/admin/auth` | POST | 登录 |
| `/api/admin/auth` | DELETE | 登出 |
| `/api/admin/books` | GET | 书籍列表（支持 search/page/limit） |
| `/api/admin/books` | POST | 创建新书 |
| `/api/admin/books/[slug]` | GET | 获取书籍详情 |
| `/api/admin/books/[slug]` | PUT | 更新书籍 |
| `/api/admin/books/[slug]` | DELETE | 删除书籍 |
| `/api/admin/isbn-lookup` | GET | ISBN 查询 Google Books API |
| `/api/admin/tropes` | GET/POST | Trope 列表/创建 |
| `/api/admin/tropes/[slug]` | PUT/DELETE | Trope 更新/删除 |
| `/api/admin/reviews` | GET/POST | 评论列表/创建 |
| `/api/admin/reviews/[id]` | DELETE | 删除评论 |

## 七、关键技术细节

- **Slug 生成规则**：书名 → 转小写 → 移除撇号/单引号 → 非字母数字替换为连字符 → 合并连续连字符 → 去除首尾连字符
- **Amazon URL 生成**：`https://www.amazon.com/dp/{ASIN}?tag=chessanalys05-20`
- **JSON 数组字段**：subgenres、content_warnings、similar_books、perfect_for、skip_if、moods 在数据库中以 JSON 字符串存储
- **Tropes 关联**：通过 `book_tropes` 中间表实现多对多关系
- **原子操作**：书籍创建/更新使用 `db.batch()` 保证 books 表和 book_tropes 表的操作原子性
- **级联删除**：删除书籍时，`book_tropes` 和 `reviews` 中的关联记录自动级联删除
